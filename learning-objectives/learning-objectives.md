# Python for Data Analysis Learning Objectives

*Last updated fall 2026*

| Week | Title | Learning outcomes |
|---|---|---|
| **1** | Advanced Python and Regex | • Set up and use a Kaggle notebook and the local `python_homework` environment.<br>• Find and extract patterns in text with regular expressions and the `re` module.<br>• Build reliable file paths with `pathlib`, and process a directory of files.<br>• Use dict comprehensions and lambdas, and parse semi-structured text into a list of dictionaries. |
| **2** | Intro to Data Engineering with Pandas | • Explain what Pandas is, and create Series and DataFrames from Python lists, dictionaries, and NumPy arrays.<br>• Load data into a DataFrame from CSV files, JSON files, dictionaries, and a web API, and save results back to CSV.<br>• Inspect an unfamiliar dataset with a repeatable first-look routine (`shape`, `head`, `info`, `describe`, `value_counts`).<br>• Select and filter the exact rows, columns, and cells I need, and count missing values with `isna().sum()`. |
| **3** | Data Cleaning and Validation | • Find, remove, and fill missing values, and decide which is appropriate.<br>• Convert columns to the right types and parse messy dates, recognizing placeholder values that hide missing data.<br>• Transform columns with operators, `.map()`, and `.apply()`.<br>• Standardize and extract text using `.str` methods and regular expressions.<br>• Validate data against ranges and allowed sets, remove duplicates, and judge outliers — while keeping an untouched raw copy. |
| **4** | Data Wrangling and Aggregation | • Summarize data by group with `groupby()` and `agg()`, using a list or a dictionary of functions.<br>• Combine DataFrames with `merge()`, `join()`, and `concat()`, choosing the right join type.<br>• Reshape data with `pivot_table()` and navigate results with `set_index`, `reset_index`, `rename`, and `sort_values`.<br>• Engineer new features with row-wise `apply()`, `pd.cut()` binning, and categorical encoding. |
| **5** | Exploratory Visualization | • Choose an appropriate chart for a question about comparison, trend, distribution, relationship, or composition.<br>• Make quick charts directly from a DataFrame with `df.plot()`, including from a `groupby` result.<br>• Build, label, and save presentation-quality charts with Matplotlib and Seaborn, and apply basic design rules.<br>• Explore an unfamiliar dataset with a repeatable EDA process and document the findings. |
| **6** | Web Scraping with Selenium | • Describe how HTML and the DOM structure a web page, and inspect a page with developer tools.<br>• Apply the ethical and legal rules of scraping: `robots.txt`, terms of service, responsible rate, and personal data.<br>• Use Selenium to load a page and locate elements with CSS selectors and XPath.<br>• Build a reliable scraper that handles errors, waits for content, and saves results to CSV, JSON, and SQLite. |
| **7** | Databases and SQL | • Explain tables, primary and foreign keys, associations, constraints, and transactions.<br>• Create and populate a SQLite database with `sqlite3`, using parameterized statements.<br>• Query data with `SELECT`, `WHERE`, `ORDER BY`, `GROUP BY`, and joins.<br>• Modify data with `UPDATE` and `DELETE`, and move data between SQL and Pandas. |
| **8** | Advanced SQL and Integration | • Aggregate across joins and filter groups with `HAVING`.<br>• Write subqueries and self-joins, and use window functions and date functions.<br>• Connect to a database with SQLAlchemy and read and write through an engine.<br>• Prevent SQL injection with parameterized queries, and use transactions and indexes. |
| **9** | Interactive Visualization and Dashboards | • Create interactive charts with Plotly and display them.<br>• Explain Streamlit's rerun-from-top execution model.<br>• Build an interactive app with widgets, layout, and a DataFrame filter.<br>• Assemble a dashboard and deploy it to Streamlit Community Cloud. |
| **10** | Final Project I: Pipeline and Analysis | • Sharpen my project into a specific, answerable question and plan my notebook.<br>• Load and clean my dataset, documenting each cleaning decision.<br>• Analyze the data with aggregations, derived features, and my Week 8 SQL queries.<br>• Support at least three findings with clear charts, and write them up in `summary.md`. |
| **11** | Final Project II: Dashboard and Presentation | • Plan a dashboard around the questions worth making interactive.<br>• Build a Streamlit dashboard that reads my cleaned data and wires filters to metrics and charts.<br>• Deploy the dashboard to Streamlit Community Cloud and prepare my repository.<br>• Record a short presentation using `summary.md` as the script, and submit the project. |
