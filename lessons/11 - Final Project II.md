# Lesson 11 — Final Project II: Dashboard and Presentation

**Lesson Overview**

This is Phase 2, the final week of the course. Last week you produced an analysis and a `summary.md`; this week you turn that work into an interactive **Streamlit dashboard**, deploy it to the web, and record a short presentation. Everything you need is already in hand: the cleaned data you committed in Week 10, the Streamlit skills from Week 9, and `summary.md`, which becomes your presentation script.

**Before you begin, review the [Final Project Overview](https://github.com/Code-the-Dream-School/python-for-data-analysis-v3/blob/main/resources/final_project_overview.md)** for the full arc and the rubric. This week is graded against the **Phase 2 rubric**.

**Learning Objectives**

This week, I can...

* Plan a dashboard around the questions worth making interactive.
* Build a Streamlit dashboard that reads my cleaned data and wires filters to metrics and charts.
* Deploy the dashboard to Streamlit Community Cloud and prepare my repository.
* Record a short presentation using `summary.md` as the script, and submit the project.

## Topics

1. **[Planning Your Dashboard](<11 - Final Project II/01_planning_dashboard.md>)**

   Deciding what the dashboard lets users explore, which filters matter, and how the page is laid out.

2. **[Building the Dashboard](<11 - Final Project II/02_building_dashboard.md>)**

   Building the planned dashboard in Streamlit, reading your cleaned data and wiring filters to metrics and charts.

3. **[Deploying Your App](<11 - Final Project II/03_deploying.md>)**

   Deploying to Streamlit Community Cloud (a repeat of the Week 9 practice) and preparing your repository and README for submission.

4. **[Recording and Submitting](<11 - Final Project II/04_submitting.md>)**

   Recording a 3–5 minute presentation using `summary.md` as the script, and submitting the final project.

## Submitting This Week

This week has one submission: a **pull request** to your project repository, with the deployed URL and the presentation video link recorded in the repository. The requirements and the Phase 2 rubric are on the [assignment page](../assignments/11 - Final Project II.md).

Congratulations on reaching the final week — this project brings together everything from the course, from loading and cleaning data to presenting an interactive analysis.
